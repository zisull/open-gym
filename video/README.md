# 影院放映目录 video/

把想看的视频放进这个文件夹，游戏里的电影院银幕就能播放。

## 用法

1. 将视频文件复制到本目录（支持 MP4 / WebM / MOV / M4V / Ogg 等浏览器可解码格式）；
2. 双击 `../tools/gen_videos.bat`（或 `npm run videos`）生成放映单；
3. 打开 `index.html`，走进球场后方的红门进入电影院：**片单里有几部，环墙上就有几块
   银幕**（3 部 3 块、5 部 5 块，均匀环绕、全部等高），站到中央圆沙发边按 **左键**
   入座即可放映。

## 两种片源

- **自动放映单（短片）**：本目录内的文件会被打包进 `manifest.js`（data: URL 内嵌）。
  受离线安全限制，单个文件超过 **25MB**、或全部内嵌超过 **40MB** 会自动跳过——
  清单太大会让 `index.html` 双击后卡近一分钟。**被跳过的文件不会出现在环墙上**，
  要用下面的方式放。
- **任意大文件**：入座后点放映条上的 **📂 选择视频**（**可一次多选**），直接选本地文件
  （含本目录里的大影片）。走 blob: URL，不占内存、不受大小限制，任何浏览器能解码的
  格式都能放；选中的会追加成新的银幕。重开页面后这类临时片源复原不了，那个位置
  显示一张写着使用说明的占位银幕，点 **↺ 恢复默认** 可退回片单排布。

> 为什么要打包：`file://` 下浏览器既不能列目录，本地路径视频直接贴到 WebGL 银幕
> 又会被判定为跨源污染（SecurityError）。data:/blob: 是两种同源、不被污染的安全来源。

`manifest.js` 是生成物，已加入 `.gitignore`，无需手动编辑。
